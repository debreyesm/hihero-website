Upload this folder to your existing Netlify site:
1. Sign in to Netlify.
2. Open hiherostaff.
3. Select Deploys.
4. Drag the unzipped hihero_multipage folder into the manual deploy area.
5. Netlify will replace the live version.

Pages: Home, For Clients, For Workers, Contact.
The contact form uses FormSubmit and sends to deborah@hiherostaff.com.
